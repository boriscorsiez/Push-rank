PUSH RANK V1 - prototype fonctionnel

1. Décompresse le dossier sur un hébergement HTTPS (la caméra iPhone nécessite HTTPS ou localhost).
2. Ouvre l'URL dans Safari sur iPhone.
3. Autorise la caméra.
4. Safari > Partager > Sur l'écran d'accueil.
5. L'app garde XP, rang, streak, total et record dans localStorage.

AUTO PUSH utilise MoveNet via TensorFlow.js dans le navigateur. La vidéo n'est pas envoyée à un serveur par ce code : elle est analysée localement par le navigateur. Le comptage est un prototype et doit être calibré/testé avec plusieurs angles avant d'être considéré fiable.
